# 手工验收清单

## 选区与鼠标

- 在每台显示器上分别创建选区，确认默认选区位于当前鼠标所在显示器且不进入菜单栏。
- 将指针放在选区中心，依次点击、双击、拖动、滚动，并在文本框输入；下方应用应正常响应。
- 指针移到蓝线时显示手形并可移动；移到线两侧或四角时显示对应缩放光标。
- 缩放期间显示逻辑点宽高，松开后立即隐藏。
- 将选区拖到不同 Retina 缩放比例的显示器，重新录制校验坐标。

## 菜单状态

- 未创建：只有“创建录制区域”和“退出”。
- 已创建：有开始、重新创建、格式、帧率、缩放比例和退出。
- 录制中：只有“结束录制”和“退出”。
- 左键点击图标不会打开命令菜单；右键会打开。
- 透明选区中没有任何按钮、计时器或控制栏。

## 输出

- 分别导出 MP4 与 GIF；使用 QuickTime/预览打开。
- 两种格式都应自动保存到桌面的 `RegionRecorder` 文件夹，录制结束后访达应自动打开并选中新文件。
- 同一时间戳已有文件时不得覆盖，应生成带 `-2` 等后缀的新文件。
- 用 `ffprobe` 或 QuickTime 检查器确认 MP4 只有一个视频轨且没有音轨。
- GIF 应自动循环，尺寸等于逻辑选区 × Retina scale × 输出缩放比例（编码尺寸按 H.264 要求取最近偶数）。
- 边框、菜单栏图标及其菜单不应出现在内容中。
- 录制开始后选区不可移动或缩放，但中心鼠标穿透仍有效。
- 拒绝屏幕录制权限时应出现说明和“打开系统设置”，且应用继续运行。
- 权限列表未显示应用时，提示中的“在访达中显示应用”应定位到当前 `.app`，可通过系统设置左下角 `+` 手动添加。
- 使用 Apple Development + Team 连续构建两次后，屏幕录制授权应保留；不要用 ad-hoc 签名验证权限持久性。
- 导出后检查系统临时目录中不残留 `com.local.RegionRecorder.recording-cache` 目录。
- 中止录制或模拟遗留会话后，确认下一次录制前会删除整个专用缓存目录。
- Build 后确认 `RegionRecorder.xcodeproj` 同级的 `app/RegionRecorder.app` 已生成；重复 Build 后该应用被新构建覆盖。
