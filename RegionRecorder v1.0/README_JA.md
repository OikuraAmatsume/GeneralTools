# RegionRecorder（macOS）

[中文 README](README.md)

RegionRecorder は、完全にローカルで動作するネイティブ macOS 用の範囲指定スクリーンレコーダーです。通常のメインウインドウはなく、メニューバーのアイコンだけで動作します。録画に関するすべての操作は、メニューバーアイコンの**右クリックメニュー**から行います。

## 動作環境とビルド

- macOS 14 以降
- Xcode 15 以降（Xcode 26.6 で動作確認済み）
- `RegionRecorder.xcodeproj` を開き、`RegionRecorder` スキームを選択して実行
- 共有 `RegionRecorder` スキームで Build するたびに、既存の `app/RegionRecorder.app` だけを事前に削除し、プロジェクトと同じ階層の同じ場所へ新しいアプリを生成します。古いプラグインやリソースは残りません
- 初回録画時に「画面収録とシステムオーディオ録音」の許可が必要です。マイクの許可は要求しません

### macOS 26 の署名と画面収録権限

画面収録の許可は、アプリのコード署名 ID に関連付けられます。初回実行前に、Xcode で `RegionRecorder` target → **Signing & Capabilities** → **Team** を開き、Personal Team または開発チームを選択してください。Debug ビルドには安定した **Apple Development** 証明書を使用します。

Team を設定しない場合、Xcode は ad-hoc（`-`）署名を使用します。macOS 26 では再ビルド後のアプリが別アプリとして扱われ、権限一覧に表示されない、または許可が保持されないことがあります。

権限一覧に RegionRecorder が表示されない場合：

1. 上記の手順で Team を選択し、再度 Build & Run します。
2. メニューバーアイコンを右クリックし、「録画を開始」をもう一度選択して、ScreenCaptureKit にシステム登録を要求させます。
3. まだ表示されない場合は、権限画面左下の `+` をクリックします。アプリの案内から「Finder に表示」を選び、表示された `.app` を一覧へ追加します。
4. スイッチをオンにした後、アプリを完全に終了して再起動します。

署名を無効にしたコマンドラインビルドも実行できます：

```sh
xcodebuild -project RegionRecorder.xcodeproj \
  -scheme RegionRecorder \
  -configuration Debug \
  -derivedDataPath /tmp/RegionRecorderDerivedData \
  CODE_SIGNING_ALLOWED=NO build
```

## 使い方

1. メニューバーの録画アイコンを右クリックし、「録画範囲を作成」を選択します。
2. 青い細枠をドラッグして範囲を移動します。枠の辺または四隅をドラッグするとサイズを変更できます。
3. メニューから MP4/GIF、フレームレート、スケールを選択します。
4. アイコンを右クリックし、「録画を開始」を選択します。
5. 録画を終了するときは、右クリックメニューから「録画を終了」を選択します。GIF の場合は停止後にローカル変換され、メニューに一時的に「書き出し中…」と表示されます。

録画結果は自動的にデスクトップの `RegionRecorder` フォルダへ保存されます。書き出しが完了すると Finder が開き、生成されたファイルが選択されます。ファイル名は `RegionRecorder-yyyyMMdd-HHmmss.mp4` または `.gif` です。同じ秒に同名ファイルが存在する場合は、`-2`、`-3` のように連番が追加されます。

選択範囲の中央にはイベントを受け取るウインドウが存在しません。クリック、ダブルクリック、ドラッグ、スクロール、キーボードフォーカスは、背後のアプリへ直接渡されます。録画中は ScreenCaptureKit のキャプチャ矩形を安定させるため、範囲の位置とサイズを固定しますが、中央部分のマウス透過は維持されます。

## 主な仕様

- `NSStatusItem` は右クリックのみを処理し、通常のメインウインドウやフローティング操作バーは表示しません。
- 透明な `NSPanel` が 2 pt の枠線を描画し、マウスイベントを無視します。移動とサイズ変更は、8 個の細い透明な辺・角用パネルだけが処理します。中央を覆うイベントマスクは使用しません。
- ScreenCaptureKit の `sourceRect` には、ディスプレイ内の左上原点ポイント座標を使用します。出力サイズは Retina の backing scale とユーザー指定スケールを反映し、偶数ピクセルへ調整します。
- キャプチャフィルターでアプリ自身の全ウインドウを除外するため、選択枠、メニュー、案内ダイアログは録画結果に入りません。
- AVFoundation では H.264 の映像トラックだけを作成し、音声入力や音声トラックは作成しません。
- GIF は無音の一時 MP4 を作成した後、AVAssetReader と ImageIO を使ってローカルで無限ループ GIF に変換します。
- 録画ごとに、システムの一時ディレクトリ内へ専用セッションフォルダを作成します。書き出し成功、失敗、手動中止のいずれでも、エンコーダーを解放してセッションフォルダ全体を削除します。次回の録画開始前には、異常終了で残ったキャッシュも削除します。GIF 変換後は Core Image のキャッシュも明示的に消去します。
- ネットワークコードやネットワーク entitlement はなく、プライバシーマニフェストでトラッキングおよびデータ収集を行わないことを宣言しています。固定のデスクトップフォルダへ確認なしで保存するため、App Sandbox は無効です。
- 接続中の任意のディスプレイで範囲を作成できます。異なる表示倍率でも正確なピクセル位置を保つため、1 回の選択範囲は 1 台のディスプレイの表示可能領域内に制限されます。別のディスプレイへ移動すると、対象ディスプレイと backing scale が自動的に切り替わります。

## テスト

`RegionRecorderTests` では、以下を検証します：

- AppKit の左下原点座標から ScreenCaptureKit のディスプレイ内左上原点座標への変換
- Retina および出力スケール適用後の偶数ピクセル寸法
- 負の座標を含むマルチディスプレイ環境での矩形計算
- 選択範囲がディスプレイの表示可能領域内に収まり、メニューバーを覆わないこと
- 透明な選択範囲の中央がヒットせず、辺だけがヒットすること
- 合成フレームから作成した MP4 に音声トラックがなく、実際の書き出し処理で解析可能な無限ループ GIF へ変換できること
- デスクトップの `RegionRecorder` フォルダ作成、拡張子、重複ファイル名回避
- 録画セッション内の MP4、GIF、入れ子のエンコーダーキャッシュ、および異常終了後の残存ファイルを完全に削除できること

画面収録権限、実環境でのマウス透過、MP4/GIF の再生、物理 Retina・マルチディスプレイでの位置合わせは、macOS 上でアプリを実行して確認する統合テストです。詳細は `TESTING.md` を参照してください。
